# Mermaid 图表技能

[中文文档](README_CN.md) | [English Documentation](README.md)

将复杂的技术概念转化为清晰、可维护的图表，让设计沟通和文档编写更高效。

## 这个 Skill 解决了什么问题

在软件开发中，我们频繁遇到这些场景：

- **设计沟通成本高** – 口头描述架构或流程，团队成员理解不一致，导致返工
- **文档长期过时** – 传统截图式图表无法版本控制，代码变了图却没更新，新人看到的是错误信息
- **绘图工具效率低** – Visio、Draw.io 等工具拖放操作繁琐，修改时牵一发而动全身，难以在代码审查中快速迭代
- **缺乏统一标准** – 不同人用不同工具画出的图风格各异，团队难以建立一致的可视化语言

这个 Skill 的目标很简单：**让画图像写代码一样自然，让文档像代码一样可维护。**

## 为什么选择 Mermaid

Mermaid 用纯文本语法描述图表，与手写代码无异，从根本上改变了技术图表的创建和维护方式：

| 特性 | 传统工具 | Mermaid |
|---|---|---|
| **版本控制** | 二进制图片，diff 无法阅读 | 纯文本，Git diff 清晰追踪每一行变更 |
| **协作效率** | 来回传文件，评论靠截图标注 | 直接在 PR / Markdown 中审查和修改 |
| **维护成本** | 改一处要重画整张图 | 文本替换，秒级更新 |
| **嵌入能力** | 导出图片再插入，分辨率受限 | GitHub/GitLab/Notion/VS Code 原生渲染 |
| **统一风格** | 因人而异，全靠自觉 | 语法即规范，产出风格天然一致 |
| **学习曲线** | 复杂界面，菜单层级深 | 几行文本，5 分钟上手 |

**一句话：如果代码能描述清楚，就不该花时间拖拽图形。**

## 安装

通过 `npx skills` 一键安装到本地：

```bash
npx skills install mermaid-diagrams
```

安装完成后，即可在对话中使用该技能生成各类 Mermaid 图表。

## 快速上手

1. **明确你想表达什么** – 架构、流程、数据模型？
2. **打开对话，描述需求** – 例如："帮我画一个用户登录的序列图"、"设计一个电商系统的数据库 ER 图"
3. **获得图表和代码** – Skill 生成 Mermaid 语法，你可以直接复制到 Markdown 或 `.mmd` 文件中使用
4. **迭代修改** – 像改代码一样调整文本，实时预览

无需安装任何软件，无需学习复杂界面，用文字描述，直接出图。

## 支持的图表类型

覆盖软件工程中最常用的可视化需求：

- **架构与系统** – C4 图、架构图、状态图
- **流程与交互** – 流程图、序列图、用户旅程图
- **数据与模型** – 类图、ER 图、思维导图
- **项目与计划** – 甘特图、看板、时间线
- **分析与展示** – 饼图、桑基图、雷达图、象限图

详见 [SKILL.md](SKILL.md) 获取图表类型选择指南和完整语法参考。

## 典型使用场景

- **设计评审前** – 快速画出方案草图，对齐团队认知后再写代码
- **API 交接时** – 序列图替代长篇文字说明，前后端一目了然
- **新人 onboarding** – 系统架构图与代码同仓库，始终最新
- **技术方案文档** – 图表嵌入 Markdown，随 PR 一起评审和迭代
- **数据库设计** – ER 图即文档，改表结构时同步更新

## 融入工作流

Mermaid 图表可在主流工具中无缝使用：

- **GitHub / GitLab** – Markdown 文件中自动渲染
- **VS Code** – 安装 "Markdown Preview Mermaid Support" 实时预览
- **Notion / Obsidian / Confluence** – 原生支持 Mermaid 语法块
- **导出** – 通过 [Mermaid Live Editor](https://mermaid.live) 或 CLI 导出 PNG / SVG / PDF

---

**核心原则：图表是代码的一部分，应当可被阅读、审查和维护。**
