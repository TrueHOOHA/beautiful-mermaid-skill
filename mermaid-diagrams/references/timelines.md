# Timelines

Timelines illustrate chronological sequences of events, dates, or periods, organized with optional sections for grouping related events.

## Basic Syntax

```mermaid
timeline
    title History of Social Media
    2002 : LinkedIn
    2004 : Facebook
    2005 : YouTube
```

## Sections

Group events into logical periods:

```mermaid
timeline
    title Product Development
    section Phase 1
        2024-01 : Project kickoff
        2024-02 : Requirements complete
    section Phase 2
        2024-03 : Design finalized
        2024-04 : Development started
    section Phase 3
        2024-05 : Testing phase
        2024-06 : Public launch
```

## Multiple Events per Period

Show multiple events at the same time:

```mermaid
timeline
    title Company Milestones
    2019 : Founded
         : First prototype
    2020 : Seed funding
         : Beta launch
    2021 : Series A
         : 1000 customers
    2022 : Series B
         : International expansion
```

## Comprehensive Example

```mermaid
timeline
    title Technology Evolution
    section Web 1.0
        1990 : World Wide Web invented
        1995 : JavaScript introduced
        1998 : Google founded
    section Web 2.0
        2004 : Facebook launched
        2005 : YouTube founded
        2006 : AWS launched
        2008 : GitHub founded
    section Mobile Era
        2007 : iPhone released
        2008 : Android launched
        2010 : Instagram launched
    section Cloud & AI
        2012 : Kubernetes created
        2015 : Docker popularized
        2020 : GPT-3 released
        2022 : ChatGPT launched
```

## Best Practices

1. **Use consistent date format** - Choose one format and stick to it
2. **Group with sections** - Organize related events together
3. **Keep descriptions concise** - Short phrases work best
4. **Show parallel events** - Use multiple entries per time period
5. **Include significance** - Highlight why events matter

## Common Use Cases

- Project roadmaps
- Product evolution
- Company history
- Historical events
- Release schedules
